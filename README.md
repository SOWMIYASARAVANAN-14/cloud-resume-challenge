# Cloud Resume Challenge — Step 1

A responsive, dark editorial-style resume portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and resume content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation, dynamic footer year, profile-link placeholders

## Run locally
1. Open this folder in VS Code.
2. Install/use the Live Server extension, then right-click `index.html` → **Open with Live Server**.
3. Or open `index.html` directly in a browser.

## Before publishing
- Verify every resume statement and project status.
- Replace GitHub and LinkedIn placeholder links in `index.html` / `script.js` with your real public profile URLs.
- Add a real downloadable PDF resume link only after you have a final PDF.
- If you hold only course completion rather than the official AWS exam credential, keep the wording accurate.
- Add the visitor-counter display and API call in a later project step, after the API Gateway, Lambda, and DynamoDB backend is working.

No frameworks or build tools are required.
